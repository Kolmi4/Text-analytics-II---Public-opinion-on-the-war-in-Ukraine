# Text Analytics: Evolution of Public Opinion on the Ukraine War

## Project Overview
This project is an analytical study investigating how global public sentiment regarding the war in Ukraine has evolved over time. We analyze Reddit discourse surrounding five major catalyst events, comparing a baseline sentiment model against a stronger machine learning approach to track shifts in public opinion.
